# Inspections Guide

Inspections support pre-work, post-work, commissioning, routine, seasonal, trip, habitation, electrical, gas, water, heating, refrigeration, chassis, tyre, body, roof, damp, safety, warranty, acceptance and custom records.

Create an inspection directly, from a generic template or for a workshop job. Perform each check explicitly, record findings, measurements and evidence, and raise defects without automatically creating faults. Incomplete checks remain incomplete. Results refer only to defined criteria; the application never uses an unqualified “safe” result.

Link inspections to jobs, systems and components. Complete and archive explicitly, preserve revision history, and print the resulting record for handover. Owner-entered inspections are not professional certification.
