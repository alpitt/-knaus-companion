# Vehicle Health guide

Vehicle Health is a transparent summary of recorded maintenance, faults, Workshop Jobs, inspections, measurements, component state, safety equipment, evidence, documents, warranties, deferrals, unknowns and Trip impacts.

The optional 0–100 score uses the visible application-defined weights in `vehicle_health_rules.json`. The category results, blockers, warnings, unknowns, sources and confidence are primary; the score is secondary. Missing evidence lowers confidence and unresolved blockers remain visible regardless of score.

The assessment covers only stored data. It is not a statement that the vehicle is safe, roadworthy, compliant or certified, and it does not predict failure. Assessment history should be retained as dated owner metadata rather than replacing source records.
