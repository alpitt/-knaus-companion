# Fault-tree guide

Nodes have stable IDs and one explicit entry node. Branch rules declare input, operator, priority, target, unknown behaviour, and sources. Equal-priority overlaps or multiple matches stop progression. Unknown paths must be explicit. Measurement branches require a unit and configured acceptance criterion; absent criteria return `no-configured-criteria`. Hold points, professional-review requirements, and source-backed escalations cannot be silently bypassed. Validation reports unreachable nodes, dead ends, missing targets, ambiguous rules, overlapping numeric ranges, invalid cycles, and unsupported operators. Intentional loops require an explicit maximum and exit. Validation never modifies the tree and never supplies missing sources, limits, hazards, or conclusions.
