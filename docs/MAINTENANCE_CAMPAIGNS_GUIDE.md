# Maintenance Campaigns guide

Campaigns group explicitly selected maintenance tasks for an annual review, winterisation, recommissioning or another owner-defined objective. Initial templates are generic administrative structures and contain no vehicle-specific interval or acceptance limit.

Create a campaign, copy a template if useful, add/reorder tasks and define explicit dependencies. Blocking and incomplete child tasks remain visible during partial completion. Workshop Job and inspection integrations create previews first. Completion and archive actions retain campaign history and never complete child maintenance automatically.
