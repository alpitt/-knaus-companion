# Systems Explorer guide

Open **Systems Explorer** to browse the documented vehicle graph. Search or filter by node type and confidence, then select a node with touch, mouse, Enter or Space. Connected nodes and edges are highlighted and the detail panel shows provenance, evidence and local owner history.

Use zoom, reset, full-screen and print controls. Dashed nodes indicate unknown confidence. An empty connection list means no relationship is documented—not that no physical connection exists. Follow links to the relevant system or ask the offline assistant for traceable reference material.

The Explorer works offline, does not modify Digital Twin reference data or owner records, and does not contact an external service.
