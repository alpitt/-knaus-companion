# Diagnostic session guide

Readiness lists missing sources, symptoms, tools, PPE, procedures, evidence, measurement capability, and review requirements. Ready does not mean safe. Starting pins the exact diagnostic version. Guided mode records each explicit response, rule ID, branch target, observation, measurement, and evidence link. Checkpoints supplement rather than replace append-only history. Pause, reload, resume, and confirmed checkpoint restore retain traceability. Deviations and branch overrides require reasons. Unresolved questions remain first-class records. Completion review lists tested scope, branch path, evidence, criteria results, escalations, limitations, and unknowns. Supported conclusion, unresolved, insufficient evidence, no-fault-found within tested scope, and escalated completion are separate. Verification is a later explicit action. Reports remain local and are not professional or roadworthiness certificates.
