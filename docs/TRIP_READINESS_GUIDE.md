# Trip readiness guide

Companion 16.1.0 adds local trip records, evidence-aware readiness review, reusable checklists, departure/arrival/return views, planning calculations and incident records.

Create a trip from **Trip readiness**. Capture a baseline when you want a dated summary of linked vehicle information, then explicitly run the readiness assessment. Missing information remains visible and an acknowledgement never clears a blocker.

All values for payload, water, gas and energy are owner-entered. Companion does not infer capacities, legal limits, consumption, roadworthiness or legal compliance. Checklist completion is a record of actions, not certification.

Trip metadata is stored in the existing local `knaus-ultimate-v1` state and included in normal JSON backups. No location, route or trip data is uploaded.
