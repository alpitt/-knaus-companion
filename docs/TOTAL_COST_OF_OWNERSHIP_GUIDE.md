# Total Cost of Ownership guide

TCO can include explicit acquisition, ownership, maintenance, repair, modification and trip ledger records. Archived, cancelled and void records are excluded by default and reported as exclusions.

Actual and estimated values are separate. Acquisition and disposal are included only when explicitly recorded. Refunds and reimbursements remain separate. Currencies are never combined or converted.

Cost per distance, night and trip uses only recorded denominators. Missing denominators return “not calculable”; mileage, nights, resale value and depreciation are never invented. Any depreciation view requires explicit acquisition and disposal values.

The formulas and record IDs are part of the result. TCO is a private owner summary, not audited accounts, tax guidance, market valuation or accounting advice.
