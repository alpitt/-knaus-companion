# Technical Library Guide

The Technical Library is a deterministic, rebuildable index over authoritative source records: chapters, Manufacturer Manual, Engineering Canon, procedures, executions, owner records and related technical records. It is not a replacement database.

Search and filters cover type, component, system, source, status and confidence. Cross-references, backlinks, conflicts and superseded material remain visible. Direct links lead back to source records.

Private items are indexed at runtime only and never written into repository static indexes. Rebuilding suppresses duplicate stable IDs, reports broken sources and does not mutate source data. There is no OCR, external search or binary evidence interpretation. Printed/exported indexes omit unnecessary personal data.
