# Evidence Library guide

Open **Evidence Library** and choose **Add evidence**. Give the item a clear title and type, then optionally select a JPEG, PNG, WebP, GIF, PDF, plain-text, CSV or JSON file. Validation appears before saving. Metadata-only entries are supported when an historical file is unavailable.

Link evidence to owner records or Digital Twin components. Verification means the owner reviewed the item; it does not mean Companion interpreted or independently authenticated it. Supersede outdated evidence rather than erasing history. Archive and restore are reversible.

Metadata can be exported as JSON. Binary files remain in IndexedDB and must be exported separately; ordinary Companion JSON backups do not contain file bytes. Keep independent copies of important legal and warranty documents.

Nothing is uploaded, OCR-processed or sent externally. Unsafe names, executable formats, empty files, mismatched extensions and incorrect signatures are rejected. Missing files remain visible rather than being silently deleted.
